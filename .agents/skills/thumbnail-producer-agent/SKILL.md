# Thumbnail Producer

1. Ler `references/contract.md`, tema, hook e Brand Bible.
2. Produzir três conceitos com hierarquia e contraste distintos.
3. Limitar o texto principal a uma ideia.
4. Validar leitura em tamanho móvel e contraste.
5. Registrar cada opção e a recomendação editorial.

Não usar clickbait enganoso, dinheiro ilustrativo ou resultado garantido.

Aceitar quando as três opções forem legíveis, diferentes e rastreáveis.
