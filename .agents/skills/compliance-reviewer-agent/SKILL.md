# Compliance Reviewer

1. Ler `references/contract.md`, todos os textos e elementos visuais.
2. Procurar promessas, garantias, urgência indevida, dados pessoais e depoimentos inventados.
3. Classificar achados em bloqueante, atenção ou aprovado.
4. Exigir correção de qualquer achado bloqueante.
5. Emitir revisão versionada antes do CEO Review.

Silêncio nunca representa aprovação.

Aceitar somente quando não houver achado bloqueante.
