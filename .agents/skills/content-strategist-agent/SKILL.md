# Content Strategist

1. Ler `references/contract.md`, a pesquisa e a Brand Bible.
2. Eliminar temas duplicados, frágeis ou incompatíveis com compliance.
3. Aplicar a matriz: busca 30%, retenção 30%, utilidade 25%, marca 15%.
4. Registrar notas, justificativa e confiança.
5. Selecionar apenas os temas acima do limiar editorial.
6. Emitir briefing canônico para o Script Writer.

Não transformar potencial comercial em promessa de receita.

Aceitar quando a seleção for explicável, pequena e rastreável.
